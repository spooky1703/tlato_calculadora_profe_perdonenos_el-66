## Infinitas soluciones: interpretación geométrica

El resultado incluye «¿Qué significan infinitas soluciones?»: explica la dimensión n − rango(A), permite recorrer parámetros con deslizadores o valores exactos escritos, y comprueba cada ecuación original. La gráfica usa una ventana finita de una recta, plano o espacio, con giro y zoom. Para más de tres incógnitas permite seleccionar tres ejes y muestra la imagen proyectada completa de la familia, que puede tener dimensión menor que la original. No es una sección con las demás variables fijadas. La base de la proyección se calcula con fracciones exactas; el dibujo usa aproximaciones y se omite con aviso cuando la escala no permite representarlo fiablemente. Los sistemas con π/Euler mantienen el aviso del modelo aproximado.

Pruebas adicionales: `node tests/espacio-soluciones.js`.
